# OnlycordUsers

Shows which people use Onlycord, lets you pick badges for your profile and change your name for yourself.

- Every Onlycord user gets a number in the order they joined (#1, #2, ...) and a Onlycord badge on their profile
- The logo with their number shows up next to Onlycord users in the member list, direct messages and voice channels
- The badge button in the top right, left of the platform spoofer, has a toggle for every Discord badge. Badges show in Discord's order with Nitro first. Turning on a higher tier (like Nitro Opal) replaces a lower one, and hides your real badge of the same kind (like a real Nitro Silver). Other Onlycord users see the badges you pick, except Discord Staff, which only shows on your own client
- The name button next to it lets you set a display name and username that only you see, everywhere in Discord, right away

Joining the user list goes through Discord's "Authorize" screen, so nobody can pretend to be someone else. Badge images are from [mezotv/discord-badges](https://github.com/mezotv/discord-badges).
